# IDE 模式

`/pw code <命名空间>` 打开。文件标签覆盖项目全部函数与 JSON 文件。

## 编辑器

- 行号 + 点击定位光标 + 当前行高亮
- 语法高亮：命令蓝 / 选择器橙 / 字符串与 JSON 绿 / 数字紫 / 注释灰 / 命名空间青
- **Ctrl+S** 保存并自动热重载；JSON 保存前语法校验（非法 JSON 阻止保存）

## 代码片段（规划书 8.1 章）

编辑器底部按钮，一键插入到光标处：

| 片段 | 内容 |
|---|---|
| execute | `execute as @a at @s if entity @s[distance=..5] run say hi` |
| score | 计分板创建 + 置 0 |
| tellraw | 彩色文本 |
| tellraw点击 | 带点击执行命令的文本 |
| 粒子 | portal 粒子 |
| 计分检测 | 分数匹配执行 |

## Tab 补全（规划书 4.2 章）

光标处按 **Tab**：
- 补全命令名（execute/tellraw/scoreboard…）
- 补全本项目函数名（`ns:xxx`）
- 多候选时在状态行列出其余选项

## 快捷键

| 键 | 功能 |
|---|---|
| Ctrl+S | 保存 + 热重载 |
| Tab | 补全 |
| Enter | 换行（execute 行自动缩进） |
| ↑↓←→ / Home / End | 光标移动 |
| Backspace | 删除（行首自动合并上行） |
| 滚轮 | 滚动 |
| 点击诊断 | 打开诊断报告（[[诊断代码]]） |
| 点击蓝图模式 | 切回蓝图画布 |
