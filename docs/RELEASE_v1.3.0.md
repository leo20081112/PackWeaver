# PackWeaver Bridge v1.3.0 Release Notes

发布日期：2026-09-26

**蓝图模式（Blender 节点编辑器式交互）**：积木编程迎来全新画布——每个积木成为带锚点（socket）的节点卡片，锚点之间拉贝塞尔导线表达执行流，像 Blender 几何节点/材质节点一样「拖锚点连线」来搭建逻辑。

## ✨ 新增功能

### 1. 节点卡片与锚点
- 每个积木 = 彩色节点卡片（按分类着色），右缘输出锚点 / 左缘输入锚点
- 「如果」节点为完整 Blender 语义：左侧「执行入」+「条件入」两个锚点，右侧「是」「否」两个输出锚点（绿/红标示）
- 条件积木（区域/手持/标签/分数/方块）只有条件输出锚点，连线到「如果」的条件锚点即接入判断

### 2. 拖拽连线（核心交互）
- 从输出锚点按下拖拽 → 贝塞尔导线实时跟随鼠标 → 落到目标输入锚点：
  - **执行流**：目标块接到源块之后（整棵子树随迁）
  - **条件入**：条件块接入「如果」节点
  - **是/否分支**：目标块成为该分支的第一个块，「如果」节点保持在原执行位置
- 防呆：不能把节点连进它自己的子树（防环）；无效锚点组合会提示
- 数据层：连线 = 积木树的重新挂接，与代码生成、积木/IDE 模式完全同源

### 3. 画布操作
- 中键拖拽（或左键拖空白处）平移画布
- 滚轮以光标为中心缩放（0.4x–2.5x）
- 分支「是 ↓」「否 ↓」标签随层级自动排布

### 4. 右键节点菜单
- ✎ 编辑参数 / ▲ 上移 / ▼ 下移 / ＋ 添加「否」分支（如果没有）/ ✕ 删除
- 左键节点体仍直接打开参数编辑

### 5. 其余
- 左侧积木面板沿用分类与等级门控（高级/自定义需 Lv.2）
- 底部代码预览改为树形缩进伪代码（if/else/for each 结构 + 生成的命令）
- 顶部可一键切换 积木模式 / IDE 模式 / 诊断，Ctrl+S 保存并热重载

## 📦 安装

Fabric Loader ≥ 0.14.21 + Fabric API（1.20.1），放入 `mods/`。入口：`/pw graph [命名空间]`，或积木模式工具栏「蓝图」按钮。

## ⚠️ 安装提醒

本 Mod 仅支持 **Fabric 1.20.x**（需 fabric-api 0.92.x）。放进 Forge 版或 1.21+ 版本会因版本依赖校验失败而**启动闪退**——上一版本已有人在 1.21.1 整合包里误装。
