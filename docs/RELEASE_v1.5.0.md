# PackWeaver Bridge v1.5.0 Release Notes

发布日期：2026-09-26

**积木块大扩充 + 蓝图成为原生编辑方式**：原生积木从 30 个扩充到 **55 个**（对照规划书第 9.3 章补全全部分类），且积木编辑默认进入**蓝图画布**（Blender 式节点锚点交互），所有新积木都带锚点、可直接拖拽连线。

## ✨ 新增积木（+25 个）

### 实体操作（新分类）
- **生成实体**（类型/坐标/自定义名字 NBT）、**清除实体**（任意选择器）、**把实体传到身边**、**给实体效果**

### 世界操作（扩充）
- **填充区域**（fill 双坐标）、**游戏规则**（keepInventory / doDaylightCycle / doMobSpawning / mobGriefing 等下拉切换）

### 消息界面（新分类）
- **创建 Boss 血条**（ID/名称/七种颜色）、**更新 Boss 血条**（显示给全员 + 数值 0-100）、**移除 Boss 血条**

### 物品经验（新分类）
- **附魔手中物品**、**清空物品**（可指定物品或全清）、**给予经验**（点数/等级）

### 数据（扩充）
- **分数运算**（= += -= *= /= %= < >，计分板间计算）、**写存储数据**（`data modify storage`）、**读存储数据显示**（tellraw nbt 组件）
- **创建计分板**积木新增**准则选择**：dummy / health / deathCount / totalKillCount / playerKillCount / trigger（trigger 自动 enable）

### 进度配方（新分类）
- **授予进度**、**撤销进度**、**解锁配方**、**锁定配方**

### 逻辑控制（扩充）
- **背包拥有物品**（Inventory NBT 检测）、**游戏模式为**、**存在实体**（新条件积木）
- **延迟执行(N tick)** 容器积木：子块经 `schedule` 延迟运行；蓝图里从它的输出锚点连线，目标块自动进入延迟体

## 🔵 原生积木 → 蓝图

- `/pw edit`、项目界面「积木模式」、IDE 模式切换按钮，现在**默认打开蓝图画布**
- 蓝图 = 每个积木是带锚点的节点卡片：拖锚点连线编排执行流、条件接入「如果」节点、是/否分支、容器体接入（循环/延迟）、贝塞尔导线、平移缩放、右键菜单
- 列表式编辑器保留为「列表模式」（蓝图画布工具栏可切换）
- 左侧积木面板同步显示全部 11 个分类 / 55 个积木（高级/自定义仍受等级门控）

## 📦 安装

Fabric Loader ≥ 0.14.21 + Fabric API（1.20.1），放入 `mods/`。仅支持 **Fabric 1.20.x**。
