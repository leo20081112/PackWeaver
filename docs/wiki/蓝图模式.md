# 蓝图模式

Blender 节点编辑器式的积木编程画布。入口：`/pw edit [ns]`、`/pw graph [ns]`，或项目界面「积木模式」按钮。

## 节点与锚点

- 每个积木 = 彩色节点卡片（按分类着色）
- **右缘输出锚点**：执行流出口
- **左缘输入锚点**：执行流入口（事件节点没有）
- **「如果」节点**：左上执行入 + 左下**条件入**（橙色）；右上「是」分支（绿）+ 右下「否」分支（红）
- **条件积木**：只有右侧条件输出锚点

## 连线操作

| 拖拽 | 语义 |
|---|---|
| 执行输出 → 输入 | 目标块（连同子树）接到源块之后 |
| 「如果」的是/否输出 → 输入 | 目标成为该分支的第一个块，「如果」保持在原执行位置 |
| 条件输出 → 「如果」的条件入 | 条件接入判断（多个条件 = AND） |
| 容器（对每个玩家/延迟执行）输出 → 输入 | 目标进入容器体（循环体/延迟体） |

- 拖拽中贝塞尔导线跟随鼠标；落点无效自动取消
- 防环：不能把节点连进它自己的子树
- 连线 = 积木树重新挂接，与代码生成完全同源

## 画布操作

| 操作 | 效果 |
|---|---|
| 中键拖拽（或左键拖空白） | 平移画布 |
| 滚轮 | 以光标为中心缩放（0.4x–2.5x） |
| 左键节点 | 打开参数编辑 |
| 右键节点 | 菜单：编辑参数 / 上移 / 下移 / 添加「否」分支 / 删除 |

## 积木面板

左侧面板：11 个分类 + 积木列表，点击添加到当前事件末尾。
「高级」「自定义」分类需要 Lv.2 学徒（创建 3 个项目），或 `/pw level unlock` 关闭限制。

## 事件切换

顶部按钮：每tick / 开始时 / 玩家加入 / 玩家死亡。
- **每tick** → 注册 `minecraft:tick` 标签
- **开始时** → 注册 `minecraft:load` 标签
- **玩家加入/死亡** → 自动生成进度触发器 + 防重复守卫标签
