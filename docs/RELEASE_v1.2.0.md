# PackWeaver Bridge v1.2.0 Release Notes

发布日期：2026-08-22

规划书功能补全版本：版本控制快照、3D 区域预览、代码片段与 Tab 补全、JSON 编辑校验、「从游戏获取坐标」、导出/运行、渐进式解锁。

## ✨ 新增功能

### 1. 版本控制：项目快照（规划书第 7 章轻量实现）
- `/pw snapshot save [ns]` —— 项目整体打包存入 `config/packweaver/backups/<ns>/`
- `/pw snapshot list <ns>` —— 快照列表（时间/大小）
- `/pw snapshot restore <ns> <id>` —— 恢复到任意历史版本并自动热重载（含防路径穿越校验）
- 项目管理界面每个项目新增「快照」按钮

### 2. 3D 区域预览（规划书第 18.4 章）
- `/pw preview` 开关：游戏世界里用橙色线框实时标出所有项目积木中「玩家在区域内」的检测范围
- 每 1 秒自动刷新，改积木坐标后线框即随之处移动——调试区域检测不再靠猜

### 3. 代码片段 + Tab 补全（规划书第 4.2 / 8.1 章）
- 代码编辑器底部片段按钮：execute / score / tellraw / 点击事件 tellraw / 粒子 / 计分检测，一键插入到光标处
- 按 Tab 补全：命令名 + 本项目函数名（`ns:xxx`），多候选时列出其余选项

### 4. JSON 文件编辑（规划书第 5 章）
- 文件标签页现在包含全部数据文件（函数 + advancements/进度 JSON 等）
- JSON 保存前自动校验语法（含尾随逗号宽容解析），非法 JSON 阻止保存并提示错误

### 5. 「从游戏获取」坐标（规划书第 10.1 / 22 章）
- 带坐标参数的积木（传送 / 区域检测 / 放方块 / 粒子）参数编辑屏新增「📍 取当前坐标」按钮
- 站在目标位置点一下，XYZ 自动填入——规划书第 22 章传送门教程的核心流程

### 6. 导出与运行（规划书第 2.4 章 ▶ 运行）
- `/pw export [ns]`（及项目界面「导出」按钮）：完整数据包 zip 导出到 datapacks 目录
- `/pw run <ns> [函数]`：重载并执行项目函数，默认运行 load

### 7. 渐进式解锁（规划书第 11.1 章）
- 等级体系：Lv.1 菜鸟 → Lv.2 学徒（3 项目）→ Lv.3 工匠（10）→ Lv.4 专家（25）→ Lv.5 大师（50）
- 「高级」「自定义」积木分类 Lv.2 解锁；`/pw level unlock` 一键关闭限制；项目界面显示当前等级

### 8. 积木增强
- 新增「注释」积木（高级分类，生成 `# 注释` 行，满足 BEST004 最佳实践）
- 「发送消息」积木新增颜色参数（白/金/红/绿/水/紫），生成带 color 的 tellraw/title

## 📦 安装

Fabric Loader ≥ 0.14.21 + Fabric API（1.20.1），放入 `mods/`。已有项目与配置完全兼容 v1.1.0。

## 🐛 已知限制

- 断点/单步调试与多人实时协作仍在路线图（见 README）
- 快照为本地 zip 备份，不含远程仓库同步
