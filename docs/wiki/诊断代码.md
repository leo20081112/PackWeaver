# 诊断代码

`/pw diag [ns]` 运行项目诊断（规划书第 17 章）。保存时也会自动检查。

## 严重度

- ✖ **error** — 会直接导致命令失败
- ⚠ **warn** — 性能或逻辑风险
- ℹ **info** — 最佳实践建议

## 规则总表

| 代码 | 级别 | 问题 | 修复方式 |
|---|---|---|---|
| CMD001 | error | 未知命令（不在原版命令表） | 手动修正拼写 |
| SEL001 | error | 无效选择器参数（如 `@a[socre=1]`） | 手动修正 |
| ID001 | error | 无效物品 ID（含相似 ID 建议，编辑距离 ≤3） | 手动修正 |
| JSON001 | error | JSON 语法错误 / 尾随逗号 | **一键修复**（尾随逗号） |
| PATH001 | error | 引用不存在的函数 | 创建函数或修正 |
| NBT001 | error | NBT/JSON 大括号不匹配 | 手动补全 |
| LOG003 | error | 函数循环调用（调用图检测） | 手动打断循环 |
| LOG004 | warn | 裸 `@e` 范围过大 | **一键修复**（补 type+distance） |
| PERF001 | warn | tick 函数命令过多（>100） | 拆分/改事件驱动 |
| PERF002 | warn | `@e[` 未指定 type | **一键修复**（补 type=zombie） |
| BEST001 | info | 传送命令硬编码大坐标 | 改相对坐标或存储 |
| BEST003 | info | 函数过长（>50 行） | 拆分为小函数 |
| BEST004 | info | 缺少注释 | 加 `#` 说明（或用注释积木） |

## 操作

- 单项修复：点击报告行右侧「修复」按钮
- 全部修复：「全部修复」按钮批处理所有可修复项并保存
- 重新诊断：修改后点「重新诊断」刷新
