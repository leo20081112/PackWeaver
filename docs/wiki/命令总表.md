# 命令总表

所有命令均为**客户端命令**（聊天栏直接输入），`[ ]` 可选参数。

## 项目与编辑

| 命令 | 功能 |
|---|---|
| `/pw project` | 项目管理界面（新建/模板/打开/导出/快照/删除） |
| `/pw edit [ns]` | 蓝图模式（默认积木编辑器，Blender 式节点交互） |
| `/pw graph [ns]` | 蓝图模式（同 /pw edit） |
| `/pw code <ns>` | IDE 模式：代码/JSON 编辑器 |

## 质量工具

| 命令 | 功能 |
|---|---|
| `/pw diag [ns]` | 智能诊断报告 + 一键修复 |
| `/pw recipe [ns]` | 配方设计器（有序/无序/熔炼 → JSON） |
| `/pw regex` | 正则测试器 |
| `/pw debugctl [ns]` | 调试控制（日志断点/条件断点/执行轨迹） |
| `/pw wiki` | 游戏内命令 Wiki + 命令拆解 |
| `/pw debug` | 调试监视（计分板/性能/桥接，每秒刷新） |
| `/pw preview` | 3D 区域预览线框开关 |

## 项目操作

| 命令 | 功能 |
|---|---|
| `/pw run <ns> [fn]` | ▶ 运行：重载并执行项目函数（默认 load） |
| `/pw export [ns]` | 导出数据包 zip 到 datapacks 目录 |
| `/pw snapshot save [ns]` | 保存版本快照 |
| `/pw snapshot list <ns>` | 快照列表 |
| `/pw snapshot restore <ns> <id>` | 恢复快照并重载 |

## 服务端命令（需要权限等级 2）

| 命令 | 功能 |
|---|---|
| `/pw reload` | 热重载数据包 |
| `/pw stats` | MSPT/TPS 性能报告 |
| `/pw bridge status` | TCP 桥接状态 |
| `/pw copier give` | 发放坐标复制器物品 |

## 其他

| 命令 | 功能 |
|---|---|
| `/pw level` | 查看等级（Lv.1 菜鸟 → Lv.5 大师） |
| `/pw level unlock` | 关闭等级限制 |
| `/pw blocks reload` | 重载自定义积木（config/packweaver/blocks/*.json） |
| `/pw templates` | 内置模板清单 |

## 快捷键

| 键 | 位置 | 功能 |
|---|---|---|
| F12 | 游戏 | 显示/隐藏叠加层 |
| Shift+F12 | 游戏 | 叠加层布局编辑 |
| Ctrl+S | 蓝图/IDE | 保存 + 热重载 |
| Tab | IDE | 补全 |
