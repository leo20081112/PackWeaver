# 快速上手

## 安装

1. 安装 [Fabric Loader](https://fabricmc.net/use/installer/) ≥ 0.14.21
2. 把 [Fabric API](https://modrinth.com/mod/fabric-api)（1.20.1 版）和 `packweaver-bridge-x.y.z.jar` 放入 `.minecraft/mods/`
3. 启动 **Fabric 1.20.1** 版本

> PCL/HMCL 用户注意：启动器使用版本隔离，jar 要放进对应版本的 `versions/<版本名>/mods/`。**不要**装进 Forge 版或 1.21+ 版本，会启动闪退。

## 创建第一个项目

1. 进入世界，聊天栏输入 `/pw project`
2. 填写**项目名**（随意）和**命名空间**（小写字母/数字/下划线，不能数字开头）
3. 翻选模板（推荐从「你好世界」开始）→ 点**创建项目**

项目保存在存档的 `datapacks/packweaver-<命名空间>/`。

## 搭积木（蓝图模式）

1. `/pw edit` 打开蓝图画布
2. 左侧选分类 → 点积木添加到当前事件
3. 从积木**右缘输出锚点**拖到下一块**左缘输入锚点**连线
4. 左键节点改参数（带坐标的积木有「📍 取当前坐标」按钮）
5. 点**保存运行** → 写入 datapacks 并热重载

详细交互见 [[蓝图模式]]。

## 写代码（IDE 模式）

- `/pw code <命名空间>` 打开代码编辑器
- 底部片段按钮一键插入 execute/计分板/tellraw 模板
- Tab 补全命令名和项目函数名
- **Ctrl+S** 保存并自动重载

## 日常工具

| 操作 | 方式 |
|---|---|
| F12 叠加层 | 显示/隐藏性能/坐标/桥接日志/帮助窗口 |
| Shift+F12 | 拖拽编辑窗口布局（保存到 config/packweaver-overlay.json） |
| 区域预览 | `/pw preview`，橙色线框=积木检测区域 |
| 坐标复制器 | `/pw copier give`，右键方块复制坐标，Shift+右键复制 NBT |
| 版本快照 | `/pw snapshot save`，`/pw snapshot restore <ns> <id>` 回滚 |
| 诊断 | `/pw diag`，错误可一键修复 |
