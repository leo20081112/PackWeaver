# PackWeaver Bridge v1.8.0 Release Notes

发布日期：2026-10-01

**游戏内调试系统**（规划书第 16 章可落地子集）：日志断点 + 函数执行轨迹，全部经真实游戏实例自动化验证。

## ✨ 新增：调试控制（第 16 章）

入口：IDE 模式「调试」按钮、调试监视「调试控制」按钮、`/pw debugctl [ns]`

- **日志断点**（16.2）：选函数 + 行号，保存后该行前自动注入 `tellraw` 输出——执行到该行即在聊天栏打印 `[PW] 行N ns:fn`
- **函数执行轨迹**（16.3）：开关打开后每个函数入口注入 `→ ns:fn` 轨迹行，运行一次即可看清完整调用顺序
- **单人调试**（16.6）：输出仅对携带 `pw_debugger` 标签的玩家生效，界面一键给自己加/移除标签；其他玩家无感知
- **断点管理**：列表可视化 + 逐个移除 + 一键清空；「保存并重载」即时生效
- 注入为保存时自动生成，关闭（删除断点/关轨迹）后保存即恢复纯净代码

## 🐛 修复

1. **聊天通道服务器命令回退**：`/tag`、`/function` 等服务器命令经聊天通道发送时被客户端命令树拦截报"未知命令"，现自动检测并转发服务器执行
2. 部署 zip 句柄锁（v1.7 轮修复的完善）：disable/enable 流程同样应用于插件

## ✅ 质量验证

- 第二轮 e2e：断点/轨迹注入经**磁盘文件断言**验证生成正确；标签过滤、函数运行、截图复核全部通过
- 全部注入基于保存时生成，不影响纯代码模式

## 📦 安装

Fabric Loader ≥ 0.14.21 + Fabric API（1.20.1），放入 `mods/`。仅支持 **Fabric 1.20.x**。
