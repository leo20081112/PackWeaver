# PackWeaver Bridge v1.4.0 Release Notes

发布日期：2026-09-26

**预设大扩充**：内置模板从 7 个增加到 **15 个**，新增 8 个完整可运行的玩法预设——创建项目时选模板即得整套数据包，覆盖跑酷、PvE 波次、经济、氛围与 QoL 五大类。

## ✨ 新增模板（⭐ = 难度）

### 玩法类
- **跑酷计时** ⭐⭐ —— 金压板开始计时、石压板检查点、铁压板终点结算，全服公告成绩（tick 精度）
- **传送点网络** ⭐⭐ —— `/trigger pw_warp set 1~3` 传送到三个预设坐标（附粒子音效），坐标在函数里一行修改
- **怪物竞技场** ⭐⭐⭐ —— 三波递进刷怪（僵尸→骷髅→凋灵骷髅），清场自动进入下一波，通关发奖；`/function ns:start` 开局
- **挖矿经济** ⭐⭐ —— 挖钻石矿自动得金币（统计型计分板，零 tick 开销），侧边栏显示余额，`/trigger pw_shop set 1` 用 10 金币换钻石块

### 氛围类
- **升级烟花** ⭐ —— 玩家升级自动放定制烟花（红金配色爆炸）+ 音效
- **昼夜播报** ⭐ —— 天亮/入夜全服播报（predicate 时间谓词实现，带状态变化检测，不刷屏）

### QoL 类
- **新手礼包** ⭐ —— 新玩家首次进入自动获得面包/铁剑/火把 + 欢迎标题（进度触发器 + tag 防重复）
- **自动门** ⭐ —— 走近自动打开活板门、离开自动关闭（坐标一行修改）

## 📚 15 个模板总览

你好世界⭐ / 传送门系统⭐⭐ / 计分板小游戏⭐⭐ / 商店系统⭐⭐⭐ / 职业系统⭐⭐⭐ / 副本系统⭐⭐⭐⭐ / 大逃杀⭐⭐⭐⭐⭐ / 跑酷计时⭐⭐ / 传送点网络⭐⭐ / 怪物竞技场⭐⭐⭐ / 挖矿经济⭐⭐ / 升级烟花⭐ / 昼夜播报⭐ / 新手礼包⭐ / 自动门⭐

所有模板均为标准 mcfunction/JSON（1.20.1 语法），生成后可用积木模式、蓝图模式或 IDE 模式继续改造；`/pw templates` 可随时查看清单。

## 📦 安装

Fabric Loader ≥ 0.14.21 + Fabric API（1.20.1），放入 `mods/`。仅支持 **Fabric 1.20.x**（放进 Forge 版或 1.21+ 会启动闪退）。
