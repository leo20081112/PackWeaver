# 服务端同步插件

**PackWeaverSync** —— 规划书第 19.1 / 20 章「插件承担 API 调用层，替代 Mod」的实现。Paper/Purpur/Spigot 1.20.x 服务端不装 Mod 即可被桌面端同步数据包。

## 安装

1. `packweaver-sync-1.0.0.jar` 放入服务器 `plugins/` 并重启
2. `/pws bridge` 确认桥接启动（HTTP 32006 / TCP 32005）
3. 端口可在 `plugins/PackWeaverSync/config.yml` 修改

## 命令

| 命令 | 功能 |
|---|---|
| `/pws reload` | 数据包热重载（`minecraft:reload`，非插件 reload） |
| `/pws stats` | MSPT/TPS 性能报告 |
| `/pws bridge` | 桥接端口状态 |

## 与 Mod 的分工

| | Fabric Mod | Sync 插件 |
|---|---|---|
| 环境 | 客户端/服务端 Fabric 1.20.1 | 服务端 Paper/Spigot 1.20.x |
| 游戏内积木/蓝图/IDE 编辑 | ✔ | ✘ |
| HTTP/TCP 桥接、部署热重载 | ✔ | ✔（协议相同） |
| F12 叠加层、坐标复制器 | ✔ | ✘ |

玩家**无需安装任何 Mod**：管理员用桌面端 `POST /pw/deploy` 推送数据包，服务器自动热重载（规划书 20.3 章避免重启策略）。

## 双向同步

- `GET /pw/list` —— 服务器上现有数据包清单
- `GET /pw/pack?name=xx` —— 下载服务器上的数据包
- `POST /pw/deploy?ns=xx` —— 推送本地数据包

## 安全

- 仅监听 `127.0.0.1`；eval/reload 主线程执行带超时；文件名白名单防穿越；下载仅限 zip
- 如需远程访问，建议前置反向代理并加鉴权（规划书 20.2 章权限管理，后续版本内置）
