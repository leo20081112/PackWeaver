# 积木参考

54 个原生积木，11 个分类。`@s` 指当前玩家（事件/循环上下文），参数可点节点修改。

## 事件（4）

| 积木 | 触发 | 说明 |
|---|---|---|
| 每 tick 执行 | 每 1/20 秒 | 注册 minecraft:tick 标签；注意性能（见 PERF001） |
| 当游戏开始时 | /reload 与世界加载 | 初始化计分板/规则；注册 minecraft:load 标签 |
| 当玩家加入游戏 | 玩家进服 | 进度触发器实现，自带防重复 |
| 当玩家死亡 | 玩家死亡 | 进度触发器实现 |

## 玩家操作（10）

| 积木 | 参数 | 生成命令示例 |
|---|---|---|
| 发送消息 | 目标/内容/位置(聊天栏·标题·动作栏)/颜色 | `tellraw @s {"text":"你好","color":"gold"}` |
| 给予物品 | 目标/物品ID/数量 | `give @s minecraft:diamond 1` |
| 传送玩家 | 目标/X/Y/Z | `tp @s 100 64 200` |
| 给予效果 | 目标/效果/秒/等级 | `effect give @s minecraft:speed 10 0` |
| 清除效果 | 目标 | `effect clear @s` |
| 恢复生命 | 目标/强度 | `effect give @s minecraft:instant_health 1 3 true` |
| 恢复饥饿 | 目标/强度 | `effect give @s minecraft:saturation 1 3 true` |
| 设置游戏模式 | 目标/模式 | `gamemode survival @s` |
| 播放音效 | 目标/音效/音量/音调 | `playsound minecraft:entity.player.levelup master @s ~ ~ ~ 1 1` |
| 生成粒子 | 粒子/X/Y/Z/数量 | `particle minecraft:portal ~ ~1 ~ 0.5 0.5 0.5 0.05 20` |

## 实体操作（4）

| 积木 | 参数 | 生成命令 |
|---|---|---|
| 生成实体 | 实体/X/Y/Z/名字 | `summon minecraft:zombie ~ ~ ~ {CustomName:'{"text":"Boss"}',CustomNameVisible:1b}` |
| 清除实体 | 选择器 | `kill @e[type=minecraft:zombie]` |
| 把实体传到身边 | 选择器 | `tp @e[type=minecraft:cow] @s` |
| 给实体效果 | 选择器/效果/秒/等级 | `effect give @e[type=minecraft:zombie] minecraft:glowing 10 0` |

## 世界操作（5）

| 积木 | 参数 | 生成命令 |
|---|---|---|
| 放置方块 | X/Y/Z/方块 | `setblock ~ ~ ~ minecraft:stone` |
| 填充区域 | 双对角坐标/方块 | `fill ~ ~ ~ ~3 ~3 ~3 minecraft:stone` |
| 设置时间 | day/noon/night/midnight | `time set day` |
| 设置天气 | clear/rain/thunder | `weather clear` |
| 游戏规则 | 规则/值 | `gamerule keepInventory true` |

## 消息界面（3）

| 积木 | 参数 | 说明 |
|---|---|---|
| 创建Boss血条 | ID/名称/颜色(7种) | `bossbar add pw:boss1 {"text":"Boss"}` + 颜色 + max 100 |
| 更新Boss血条 | ID/数值0-100 | `bossbar set players pw:boss1 @a` + `value` |
| 移除Boss血条 | ID | `bossbar remove pw:boss1` |

## 物品经验（3）

| 积木 | 参数 | 生成命令 |
|---|---|---|
| 附魔手中物品 | 附魔/等级 | `enchant @s minecraft:sharpness 3` |
| 清空物品 | 目标/物品ID(可空) | `clear @s` / `clear @s minecraft:diamond` |
| 给予经验 | 目标/数量/类型 | `experience add @s 10 levels` |

## 数据（6）

| 积木 | 参数 | 生成命令 |
|---|---|---|
| 设置计分板 | 目标/计分板/操作(设置·增加·减少)/数值 | `scoreboard players add @s kills 1` |
| 分数运算 | 目标A/板A/运算符/目标B/板B | `scoreboard players operation @s coins += @s coins`（= += -= *= /= %= < >） |
| 添加/移除标签 | 目标/标签/操作 | `tag @s add class.warrior` |
| 创建计分板 | 名称/显示名/准则/显示位置 | `scoreboard objectives add kills dummy "击杀数"`（准则：dummy/health/deathCount/totalKillCount/playerKillCount/trigger，trigger 自动 enable） |
| 写存储数据 | key/路径/值 | `data modify storage mydata count set value 1` |
| 读存储数据显示 | 目标/key/路径 | `tellraw @s {"nbt":"count","storage":"mydata"}` |

## 进度配方（4）

|---|---|---|
| 授予进度 | 目标/进度ID | `advancement grant @s only story/mine_diamond` |
| 撤销进度 | 目标/进度ID | `advancement revoke @s only story/mine_diamond` |
| 解锁配方 | 目标/配方ID | `recipe give @s minecraft:diamond_sword` |

## 逻辑控制（11）

**容器**（有子体，蓝图中从输出锚点连线接入）：

| 积木 | 参数 | 生成方式 |
|---|---|---|
| 如果…那么 | 备注 | 多个条件 AND：`execute if <条件1> if <条件2> run function 子函数`；有否分支生成 unless 分支 |
| 对每个玩家 | 筛选/标签 | `execute as @a at @s run function 子函数` |
| 延迟执行(N tick) | 延迟 tick | `schedule function 子函数 20t` |

**条件**（连入「如果」的条件入锚点）：

| 条件 | 参数 | 生成 |
|---|---|---|
| 玩家在区域内 | X/Y/Z/DX/DY/DZ | `entity @s[x=100,y=64,z=100,dx=2,dy=2,dz=2]` |
| 手持物品 | 物品ID | `entity @s[nbt={SelectedItem:{id:"minecraft:diamond_sword"}}]` |
| 背包拥有物品 | 物品ID | `entity @s[nbt={Inventory:[{id:"minecraft:diamond"}]}]` |
| 拥有标签 | 标签 | `entity @s[tag=class.warrior]` |
| 计分板分数 | 计分板/比较/数值 | `score @s kills matches 10..`（≥ ≤ > < =） |
| 位置是方块 | X/Y/Z/方块 | `block ~ ~-1 ~ minecraft:oak_door` |
| 游戏模式为 | 模式 | `entity @s[gamemode=survival]` |
| 存在实体 | 实体类型 | `entity @e[type=minecraft:zombie]` |

## 高级（4）

| 积木 | 参数 | 说明 |
|---|---|---|
| 调用函数 | 函数名 | `function ns:main` |
| 注释 | 文本 | 生成 `# 注释` 行（满足 BEST004） |
| 执行原始命令 | 命令 | 任意原版命令逃生舱 |
| 自定义代码块 | 命令 | 兼容旧文件/不可解析行 |

## 自定义积木（JSON 插件，规划书第 19 章）

`config/packweaver/blocks/*.json`：

```json
{"type": "distance", "name": "计算距离", "command": "data get storage my_plugin:calc {key}"}
```

`/pw blocks reload` 热加载，`{key}` 成为可编辑参数，出现在「自定义」分类。
