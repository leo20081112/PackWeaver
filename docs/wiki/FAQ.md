# FAQ

## 兼容性

**Q: 启动就闪退？**
A: 最常见原因是装错版本——本 Mod 只支持 **Fabric 1.20.x**（需 fabric-api 0.92.x）。放进 Forge 版、1.21+ 版本会因加载器版本校验失败直接闪退。PCL/HMCL 版本隔离时，jar 要放进 `versions/<版本名>/mods/`。

**Q: 可以在没有安装 PackWeaver 的服务器使用生成的数据包吗？**
A: 可以。生成的数据包是标准格式（pack.mcmeta + data/），任何原版/服务端都能用。导出：`/pw export`。

**Q: 数据包和 Mod 有什么区别？**
A: 数据包用原版命令和 JSON，所有玩家无需安装即可生效；Mod 需要修改游戏代码，每个客户端都要装。

**Q: 多个数据包能同时用吗？**
A: 能。Minecraft 按加载顺序叠加生效，`/reload` 后生效。

**Q: 数据包会损坏存档吗？**
A: 正常不会。建议测试新数据包前 `/pw snapshot save` 打快照。

## 使用

**Q: 技术模式（蓝图）和 IDE 模式的数据会丢失吗？**
A: 不会。两种模式共享同一数据源（积木树 + 函数文件），互切实时同步。IDE 手写的同名文件优先于积木生成。

**Q: 蓝图里怎么把积木放进「对每个玩家」循环体？**
A: 从循环积木的输出锚点拖到目标块的输入锚点——目标会进入循环体（而不是排在后面）。

**Q: 「如果」的多个条件是 AND 还是 OR？**
A: AND（全部满足才执行）。把多个条件积木都连进同一个「如果」的条件锚点即可。

**Q: 等一会儿再执行怎么做？**
A: 用「延迟执行(N tick)」容器积木，子块经 `schedule` 延迟运行。注意：延迟体执行时 @s 上下文由 schedule 决定（服务器执行），需要玩家上下文请在延迟体内再套「对每个玩家」。

**Q: 快照存哪里？能恢复吗？**
A: `config/packweaver/backups/<ns>/*.zip`。`/pw snapshot restore <ns> <id>` 恢复到任意历史版本并自动重载。

## 性能

**Q: 游戏卡顿？**
A: `/pw stats` 看 MSPT；`/pw diag` 查 PERF 系列问题（tick 命令过多、裸 @e）。常见优化：`@e` 加 `type=` 和 `distance=`、tick 循环改事件驱动、大函数拆分。

## 其他

**Q: 端口 32005/32006 被占用？**
A: Mod 端口是编译期常量；Sync 插件端口在 config.yml 改。客户端 Mod 和服务端插件同时在本机运行时需错开。

**Q: 怎么分享我的数据包？**
A: `/pw export` 导出 zip，对方解压到自己存档的 `datapacks/` 文件夹，或整包发送后 `/reload`。
