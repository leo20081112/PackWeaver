# 桥接协议

两个本机回环桥接（规划书第 18/20 章），供 PackWeaver 桌面端 / 外部工具连接。**只监听 127.0.0.1，外网不可访问。**

## HTTP 桥接（端口 32006）

Content-Type: application/json；CORS 全开（浏览器可直连）。

| 端点 | 方法 | 说明 |
|---|---|---|
| `/pw/ping` | GET | 连通性，返回 mod 类型与版本 |
| `/pw/stats` | GET | `{"mspt_avg":3.2,"mspt_max":8.9,"tps":20,"status":"good"}` |
| `/pw/list` | GET | 列出存档 datapacks 目录 `{"packs":[{"name":"x.zip","bytes":123}]}`（仅 Sync 插件） |
| `/pw/pack?name=x` | GET | 下载数据包 zip（仅 Sync 插件） |
| `/pw/eval` | POST | body `{"command":"say hi"}`，主线程执行控制台命令 |
| `/pw/reload` | POST | 数据包热重载（主线程 `minecraft:reload`） |
| `/pw/deploy?ns=myproj` | POST | body = 数据包 zip 字节，写入存档并自动重载 |

示例（PowerShell）：

```powershell
Invoke-RestMethod http://127.0.0.1:32006/pw/ping
Invoke-RestMethod -Method Post http://127.0.0.1:32006/pw/reload
Invoke-RestMethod -Method Post http://127.0.0.1:32006/pw/deploy?ns=demo -InFile .\demo.zip
```

## TCP 桥接（端口 32005）

按行 JSON 请求，逐行 JSON 应答（与 Mod v1.0 起保持兼容）：

```json
{"action": "ping"}
{"action": "eval", "command": "say hello"}
{"action": "reload"}
{"action": "stats"}
```

PowerShell 测试：

```powershell
$c = New-Object Net.Sockets.TcpClient('127.0.0.1', 32005)
$w = New-Object IO.StreamWriter($c.GetStream()); $w.WriteLine('{"action":"ping"}'); $w.Flush()
(New-Object IO.StreamReader($c.GetStream())).ReadLine()
```

## 端口配置

- **Fabric Mod**：编译期常量（TCP 32005 / HTTP 32006）
- **PackWeaverSync 插件**：`plugins/PackWeaverSync/config.yml` 可改

与 Fabric Mod 客户端同机时会占用相同端口——插件只应装在服务端。
