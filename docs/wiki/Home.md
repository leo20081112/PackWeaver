# PackWeaver Bridge — 全部在游戏内的 Minecraft 数据包 IDE

依据《PackWeaver v1.0 完整规划书》实现：**技术模式（积木/蓝图）+ IDE 模式**双模式数据包开发环境，全部内置于 Minecraft，无需任何外部程序。

| | |
|---|---|
| 加载器 | Fabric 1.20.1（Java 17+） |
| 服务端插件 | Paper/Purpur/Spigot 1.20.x（[PackWeaverSync]([[服务端同步插件]])） |
| 许可证 | MIT |
| 仓库 | https://github.com/leo20081112/PackWeaver |

## 核心能力

- **蓝图画布**（默认积木编辑器）：每个积木是带锚点的节点卡片，拖锚点连线编排执行流（Blender 式交互），54 个原生积木、11 大分类
- **IDE 模式**：mcfunction/JSON 编辑器，语法高亮、片段插入、Tab 补全、Ctrl+S 保存即热重载
- **双模式同源**：积木树 ⇄ mcfunction 互相转换，互切不丢数据
- **智能诊断**：CMD/SEL/ID/JSON/PATH/NBT/LOG/PERF/BEST 系列规则 + 一键修复
- **15 个内置模板**：传送门、职业系统、大逃杀、跑酷计时、怪物竞技场……
- **F12 叠加层**：性能/坐标/桥接日志/帮助四窗口，Shift+F12 拖拽布局
- **版本快照**：项目历史打包备份，一键恢复
- **3D 区域预览**：世界中橙色线框实时显示检测区域
- **双桥接**：HTTP + TCP 本机回环，桌面端可部署数据包并热重载；服务端另有 PackWeaverSync 插件

## 60 秒上手

1. Fabric Loader ≥ 0.14.21 + Fabric API（1.20.1）+ 本 Mod 放入 `mods/`
2. 进入世界 → `/pw project` → 填项目名/命名空间 → 选模板 → 创建
3. `/pw edit` 打开蓝图画布搭逻辑 → 「保存运行」写入 datapacks 并热重载
4. `/pw diag` 检查问题 → `/pw wiki` 查命令文档

> ⚠ 本 Mod 仅支持 **Fabric 1.20.x**。放进 Forge 版或 1.21+ 会因版本校验失败而启动闪退。
