# 内置模板

`/pw project` 创建项目时选择，`/pw templates` 查看清单。所有模板都是完整可运行的数据包，生成后可用蓝图/IDE 模式继续改造。

## ⭐ 入门

| 模板 | 学习内容 | 要点 |
|---|---|---|
| 你好世界 | 消息发送、函数调用 | load 事件触发 hello 函数 |
| 升级烟花 | custom 统计、召唤 NBT | level_up 统计 → 定制烟花 |
| 昼夜播报 | predicate 谓词、状态检测 | time_check 谓词 + 状态变化检测 |
| 新手礼包 | 进度事件、防重复 | 首次进服发面包/铁剑/火把 |
| 自动门 | 区域检测、方块状态 | 靠近开门离开关门，坐标一行改 |

## 通用说明

- 模板中 `100 64 100` 等占位坐标需按地图修改（对应函数里有注释）
- 带 `start.mcfunction` 的模板用 `/function ns:start` 开局
- 所有模板基于 1.20.1 语法；手写文件与积木生成同名时手写优先
