# PackWeaver Bridge v1.1.0 Release Notes

发布日期：2026-08-22

**PackWeaver 全部进入游戏内**：本版本把规划书中的 IDE 模式、技术模式（积木编程）、诊断系统、模板、Wiki 联动与调试监视全部实现为 Minecraft 游戏内界面——无需任何外部程序，进游戏即可开发数据包。

## ✨ 新增功能

### 1. 技术模式：游戏内积木编辑器（规划书第 9-11 章）
- `/pw edit` 打开积木编辑器：左侧 7 大分类积木面板，中央积木栈画布
- 事件积木：每 tick / 游戏开始时 / 玩家加入 / 玩家死亡
- 操作积木：发消息、给物品、传送、效果、音效、粒子、放方块、时间天气、计分板、标签等 20+
- 逻辑积木：如果…那么…否则、区域/手持/标签/分数/方块条件、对每个玩家循环
- 点击积木编辑参数（文本直接输入，选项循环切换），支持 ▲▼ 移动 / ✕ 删除 / 设为插入点
- 底部实时显示生成的命令——「边用边学」（第 11.1 章）

### 2. IDE 模式：游戏内代码编辑器（规划书第 4 章）
- `/pw code <命名空间>` 打开 mcfunction 编辑器：行号 + 光标定位（点击任意位置）
- 语法高亮：命令蓝 / 选择器橙 / 字符串绿 / 数字紫 / 注释灰
- 文件标签快速切换，Ctrl+S 保存并自动热重载
- 一键跳转积木模式 / 诊断

### 3. 双模式共享数据（规划书第 1.3 章）
- 积木 AST 与函数文件同源于项目元数据，两种模式随时互切
- 积木保存即生成合法 mcfunction（if/循环自动拆分子函数 + tick/load 标签 + 进度触发器）

### 4. 项目与模板（规划书第 12 章）
- `/pw project` 项目管理：命名空间校验、模板选择、打开/删除
- 7 个内置模板一键生成：你好世界⭐ / 传送门系统⭐⭐ / 计分板小游戏⭐⭐ / 商店系统⭐⭐⭐ / 职业系统⭐⭐⭐ / 副本系统⭐⭐⭐⭐ / 大逃杀⭐⭐⭐⭐⭐
- `/pw templates` 查看模板列表

### 5. 智能诊断系统（规划书第 17 章）
- `/pw diag` 生成诊断报告：错误/警告/提示分级统计
- 规则：CMD001 未知命令、SEL001 无效选择器参数、ID001 无效物品ID（含相似建议）、JSON001 语法错误、PATH001 引用不存在函数、NBT001 括号不匹配、LOG003 循环调用、LOG004/@e 范围过大、PERF001 tick 命令过多、PERF002 @e 缺类型、BEST001 硬编码坐标、BEST003 函数过长、BEST004 缺注释
- 快速修复：JSON001 去尾随逗号、PERF002 补 type、LOG004 加范围——单项修复 / 全部修复

### 6. Wiki 联动与命令拆解（规划书第 6 章 / 扩展 C）
- `/pw wiki`：15 个常用命令/知识点的中文速查（execute 子命令表、计分板准则、data 操作、NBT 类型…）
- 命令拆解器：粘贴任意命令 → 逐段中文解释 + 「人话」总结

### 7. 调试监视（规划书第 16.4 章）
- `/pw debug`：MSPT/TPS 性能、桥接状态、计分板目标与分数实时监视（每秒刷新）

### 8. 自定义积木（插件，规划书第 19 章）
- 在 `config/packweaver/blocks/*.json` 定义积木：`{"type":"distance","name":"计算距离","command":"data get storage calc {id} {path}"}`
- `/pw blocks reload` 热加载，模板中的 `{占位符}` 自动变成参数

### 9. HTTP 桥接（规划书第 20 章）
- 新增 `http://127.0.0.1:32006/pw/`：`ping` / `stats` / `eval` / `reload` / `deploy`（POST zip 部署进存档并重载），带 CORS，供外部工具集成
- 原 TCP 桥接（32005）保持不变

## 📦 安装

1. Fabric Loader ≥ 0.14.21 + Fabric API（1.20.1）+ 本 jar 放入 `mods/`
2. 进入世界后输入 `/pw project` 创建第一个项目
3. F12 查看叠加层，`/pw edit` 开始搭积木

## 🐛 已知限制

- 积木画布为结构化编辑（非自由拖拽），适合手柄/键盘与触屏一致的操作
- 分步调试（断点/单步）尚未实现，当前为静态诊断 + 实时监视
- 多人实时协作、社区模板市场列入后续版本路线
